All fixtures in this folder are hand-authored synthetic workshop records,
revision 1 (2026-11-06), released under CC0 1.0 Universal:
https://creativecommons.org/publicdomain/zero/1.0/ . They contain no real
people, venue records or customer data.

`access-note.png` is a rendering of `access-note.txt`, made by `make_document.py`.
The text file is its human-readable source, not an OCR response. Experiment 02
sends the image to SIE OCR and stores the actual returned text. `correction.txt`
is an authored policy correction for experiment 04; it is deliberately absent
from experiment 01's initial memory.
